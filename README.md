# Cave

Why dart?

```math
\begin{aligned}
\mathrm{Dart}
&=
\underset{\ell \in \mathcal{L}}{\arg\min}\; f(\ell), \\[4pt]
f(\ell)
&=
C_{\mathrm{performance}}(\ell)
+
C_{\mathrm{usability}}(\ell)
+
C_{\mathrm{cross\text{-}platform}}(\ell).
\end{aligned}
```

That's the balance between cpp and python.
